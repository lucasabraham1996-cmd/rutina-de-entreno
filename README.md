# Rutina de Entreno

App móvil para seguir una rutina semanal orientada a bajar grasa, ganar fuerza y músculo en brazos/espalda, mejorar el estado para fútbol y fortalecer gemelos.

Incluye:

- rutina base de 45 minutos;
- martes de descanso;
- viernes de fútbol;
- bicicleta exterior opcional;
- personalización semanal o por día de grupos musculares;
- tutoriales paso a paso y animaciones;
- registro de sesiones, molestias de gemelos y progreso;
- pesaje diario establecido a las 20:30, antes de cenar;
- guardado local inmediato y sincronización con Firebase/Cloud Firestore;
- recuperación del estado al volver a abrir la app;
- soporte PWA para agregarla a la pantalla de inicio del celular.

La web se publica con GitHub Pages mediante el workflow incluido en `.github/workflows/pages.yml`.
