# Rutina de Entreno

App móvil para seguir una rutina semanal orientada a bajar grasa, ganar fuerza y músculo en brazos, mejorar el estado para fútbol y fortalecer gemelos.

Incluye:

- rutina de 45 minutos;
- martes de descanso;
- viernes de fútbol;
- tutoriales paso a paso;
- animaciones de los ejercicios;
- registro local de sesiones, molestias de gemelos y progreso;
- soporte PWA para agregarla a la pantalla de inicio del celular.

La web se publica con GitHub Pages mediante el workflow incluido en `.github/workflows/pages.yml`.
